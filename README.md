# AttendX Test Scripts

This repository contains sample automation test scripts for the AttendX student attendance application.

## Test scripts

- `login_test.js`: verifies that a student with valid credentials can log in.
- `attendance_marking_test.js`: verifies that a student's attendance can be saved with the `Present` status.

## Running the examples

Install Node.js, open this folder in a terminal, and run:

```powershell
node login_test.js
node attendance_marking_test.js
```

Both scripts print a `PASS` message when the example assertions succeed.
